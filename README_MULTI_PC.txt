GeoAudit Studio V53 - Portable Multi-PC
=======================================

طريقة التشغيل على أي جهاز Windows:
1) فك الضغط عن الملف بالكامل.
2) شغل INSTALL_AND_START_GeoAudit.bat.
3) لو Python موجود: التطبيق يفتح فورًا.
4) لو Python غير موجود: السكربت يحاول تثبيته تلقائيًا مرة واحدة عبر winget، ثم يشغل GeoAudit.
5) أول مرة على كل جهاز قد تحتاج تسجيل الدخول لموقع العمل داخل نافذة المتصفح التي يفتحها GeoAudit.

مهم:
- كل جهاز يحتفظ بجلسة المتصفح الخاصة به في LocalAppData، لذلك بيانات الدخول لا تنتقل بين الأجهزة.
- لا تشغل التطبيق مباشرة من داخل ملف ZIP؛ فك الضغط أولًا.
- لا يحتاج Cloudflare لكي يعمل محليًا.

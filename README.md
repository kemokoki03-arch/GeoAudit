# GeoAudit Studio V30

## التشغيل
شغّل `START_GeoAudit.bat` فقط.

## الجديد
- زر نسخ المساحة ينسخ القيمة مع الوحدة: `م2` أو `فدان`.
- اختيار الترميز والتهشير موجود داخل نافذة معاينة CAD فقط.
- التهشير يدوي: اختر **اختيار أماكن التهشير** ثم اضغط على الـPolygon داخل المعاينة. الضغط مرة ثانية على نفس المنطقة يلغي التهشير.
- الحروف الإنجليزية A–Z توضع يدويًا داخل معاينة CAD.
- ملف تعريف المتصفح أصبح ثابتًا في Windows، لذلك سجل دخولك إلى موقع العمل مرة واحدة واختر حفظ كلمة المرور إذا عرضها Edge/Chrome، وستستمر الجلسة مع الإصدارات التالية.
- باقي أدوات GIS والتصدير ورفع CAD/Shapefile لم تتغير.


V52: One Copy button. Numeric fields paste the number only; description fields paste number + unit (م2 / فدان).

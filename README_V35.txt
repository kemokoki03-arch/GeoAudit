GeoAudit Studio V35

Changes:
- Click any layer card to highlight that layer on the map.
- Duplicate geometry is not added twice.
- New Shapefile ZIP/RAR downloads from the work site are imported automatically and fit to the map silently.
- Shift+S clears Shapefile and point layers silently. Shift+Z restores the last cleared set.
- Visual Move dialog includes Select All for all visible layers.
- Existing CAD, area, RAR, export and browser-profile features remain unchanged.
